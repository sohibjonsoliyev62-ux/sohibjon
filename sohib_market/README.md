# Sohib Market

Transport vositalari sotiladigan internet-do'kon sayti. Bitta `index.html` faylda — HTML, CSS va JavaScript. Hech qanday server yoki kutubxona kerak emas.

**Onlayn ko'rish:** https://sohibjonsoliyev62-ux.github.io/sohibjon/sohib_market/

## Ishga tushirish

- `index.html` ni ikki marta bosing — brauzerda ochiladi.
- VS Code'da: **Live Server** kengaytmasi → `index.html` ustida o'ng tugma → **Open with Live Server**.
